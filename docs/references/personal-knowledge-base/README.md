## 使用边界

- 原文逐字节复制，未修改个人知识库。原文中的路径和内部链接按来源语境保留，部分链接无法在此参考目录中直接跳转；不为补全链接复制知识正文或归档。
- 两份副本均使用 `.source.md` 文件名，作为资料阅读，不替代项目根目录的 `AGENTS.md`，也不自动成为实战 Agent 的系统提示词。
- 原规则中的个人目录、Codex 维护流程和审批方式不直接套用到本项目。可复用的知识组织与维护原则，需要结合本项目需求讨论并转为明确的设计。
- 具体存储技术、知识入库流程、自动写入范围和审核策略仍待确定。
- 不自动与个人知识库同步；后续规则发生变化时，先对照并确认参考范围，再更新快照和相关项目决定。
