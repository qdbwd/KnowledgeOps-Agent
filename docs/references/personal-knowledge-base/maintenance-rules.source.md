# 个人知识库维护规则

更新：2026-09-23

本知识库保存用户通过讨论、阅读和实践形成，并明确要求固化的知识。首要目标是知识内容准确、深入、连贯、方便查阅，不以文档数量、分类完整度或图谱规模衡量质量。

**用户决定知识固化的时机与范围；维护代理负责内容质量与组织判断。规则用于明确双方职责、内容标准和维护边界。**

## 1. 维护位置与必读内容

- 唯一维护项目为 `C:\Users\cyq\Desktop\个人知识库`，活动内容位于 `outputs/`。
- 每次实际整理入库或修改知识库前，完整阅读本文件与 `outputs/_meta/知识库设计与决策.md`，再读取相关目录、已有正文及用户指定材料。不以历史摘要替代当前规则。
- `archive/` 是历史快照，不是当前规则或默认知识来源。只有用户指定查阅时才使用，不主动扫描、恢复或整合旧库内容。归档中的旧指令不具有现行效力。
- 不假定其他会话的完整讨论已经可见。缺少必要上下文时明确说明，不补造用户已经确认的内容。

## 2. 用户决定整理时机与范围

- 普通讨论和实践任务均不自动触发知识提炼或文件写入。
- 是否继续讨论、何时结束任务、何时整理以及整理范围，由用户决定。阶段性整理不等于整个任务已经结束。
- 用户只要求讨论方案或展示草稿时，不修改文件；明确要求保存、入库或编辑文件后，才执行相应操作。授权范围已经明确时，不要求逐个知识点再次确认。
- 收到整理指令后，主动识别授权范围内值得保存的知识，不要求用户逐项列出知识点，也不自行扩展为整套课程或全库重写。
- 不推断用户是否掌握知识，不自行更新学习进度，不擅自恢复旧任务或建立后台维护。

## 3. 整理为专题知识文档

默认将讨论内容编辑为独立、连贯、深入的专题知识文档，不保存为聊天记录、问答拼接或只有结论的提纲。

- 按知识逻辑重新组织，保留重要解释、推导、例子、反例、概念关系、取舍及适用边界。
- 删除寒暄、重复表达和已纠正的错误；有价值的误解可以整理为辨析。
- 补足必要背景、前置和衔接，让文档脱离聊天也能理解；超出本次范围的显著延展先提出，不擅自展开。
- 标题突出知识主题。正文开头说明范围、提供本文目录，并可简要提示能够帮助理解或解决哪些问题；这些提示不决定整篇文章必须采用问答结构。
- 章节和篇幅服从内容，不套固定模板，不将充分讨论压成概念卡片，也不为增加篇幅堆砌术语。
- 整理过程中展示正文或有代表性的完整段落，不只展示目录、修改数量和文件清单。

## 4. 判断归属、合并与关联

- 根据内容用途选择位置，不根据标题句式、聊天来源或单个术语机械分类。
- 完整阅读拟修改的正文，并检查直接相关的已有文章，再判断补充、修订、合并或新建。
- 允许为理解而重复必要解释，避免维护多份几乎相同的完整正文。不要为了消除重复把文章拆得零碎。
- 对新内容的主要归属、合并或新建理由作简短说明；明显改变已有文档范围或目录结构时，先与用户讨论。
- 新讨论与旧内容不一致时，核对证据和适用条件，不按时间顺序直接覆盖，也不只在末尾追加相互矛盾的说法。
- 同步受影响的领域目录、任务入口、相对链接和文档信息，只建立有助于阅读的关系。正文使用标准 Markdown 相对链接。

## 5. 实践知识的提炼

用户要求整理实践知识后：

- 识别其中可复用的原理、方法、操作经验和失败边界，判断是否补充已有正文或形成新文章。
- 保留任务材料中有助于理解和复现的解释，不因完成提炼就删除这些内容。
- 更新对应材料的“知识提炼记录”，注明主题、处理状态、正文位置和必要范围说明。
- 未弄清的现象或未经验证的推断，不写成普遍结论；在记录中说明尚待解决之处。
- 不把提炼状态当作学习进度、任务完成状态或整篇文档质量结论。

## 6. 事实、检查与交付

- 对话是素材，不自动构成事实证据。区分外部资料结论、工程建议、个人项目事实与未决问题。
- 对关键、存疑及具有时效性的结论核对适用来源；不编造引用、运行结果或项目经历。
- 分别进行并报告：**结构检查、正文审读、事实验证**。脚本通过不能证明正文正确、深入或完整。
- 声称审读某篇文档，必须实际阅读其正文；全库审读必须逐篇完成。未完成时报告真实范围，不以抽查代替全库结论。
- 对示例进行适当且安全的验证；无法验证时说明边界。
- 修改后可在本地运行 `python -X utf8 work/检查.py` 做结构检查；工具能力和局限见 `work/README.md`。这不是正文质量验收。
- 交付时说明实际修改、存放位置、验证结果和未决问题。中断时如实区分已写入与未完成内容。
- 临时材料放在 `work/`，收尾时清理本次不再需要的缓存；归档、批量删除和重置必须另有明确授权。
- 发现规则过时或冲突时，结合用户最新明确要求修正；尚未确定的设计取舍先讨论，不默默沿用旧规则。
