# Harness 执行权限交付核对

日期：2026-10-14。对应[确认实施计划](implementation-plan.md)。本轮计划范围已完成；以下是机制与兼容性的工程验收，不是模型研究、写作或风险判断能力的效果评估。

## 实际运行发生了什么变化

原来模型选中已开放的命令工具后，就可以进入本地执行。现在会话默认使用“请求批准”：模型提出命令，应用先保存具体调用与审批批次，LangChain 的人工介入中间件让图暂停，PG 检查点保存暂停位置。用户处理完该批动作后，原有持久调度继续同一个运行，不需要另外点恢复，也不创建第二个任务。文件读写和公开检索仍按原工具配置使用；知识发布和 MCP 保留各自的业务授权。

权限判断分成提议后和执行前两次。前者决定是否需要询问，后者防止用户在等待期间取消任务、插入新要求、关闭工具或撤销规则后，旧批准仍启动操作。会话可以选择自动执行，但不能覆盖明确的拒绝规则、工具/角色上限、资源撤回和原业务授权。思考强度也保存为会话默认，普通任务、学习自动推进和子任务使用一致的继承路径；已经开始或恢复的运行保留原模型参数。

反复批准相同简单命令时，可以保存本会话或跨会话规则。规则按工作区、工作目录和参数数组匹配，匹配方法借鉴 Codex execpolicy；Bash 语法直接交给 tree-sitter-bash 解析。组合命令、变量展开、重定向和解释器调用仍能逐次批准，但不能被包装成宽泛的长期允许规则。规则属于权限数据，不从聊天记忆或 Skill 文本提取。

恢复还必须处理“命令已经写了文件，但结果没能保存”的情况。新增命令回执在启动前保存尝试和预算，已保存结果可直接重放；执行结果不确定时保留为 unknown，由用户核对后跳过或明确重试。跳过反馈结果未知，重试记录新尝试并重新消耗工具预算。取消后即使手动恢复，存在 unknown 的任务也先回到核对界面，不立即重跑。这里没有承诺任意 Shell 严格只执行一次。

核心中断直接复用 LangChain / LangGraph 和已有 PG 保存器，调度继续使用项目原有 outbox。DeerFlow 提供的是“可见能力过滤与执行前检查分开”的设计参照；没有整体引入它的身份系统或第二套 Harness。详细开发解释见[当前架构](architecture.md)，固定参考版本与新增依赖的许可见[决策0025](decisions/0025-execution-permissions.md)。

## 证据如何解读

后端首次完整批次执行 704 项，有 3 项失败。文件同步测试没有选择现在需要的命令自动模式，精准压缩测试混入了新技能目录的输入长度，SSE 测试替身缺少现有 Host 配置；修正这些测试前提后定向复核通过，没有放宽应用的权限或容量限制。其后新增取消后 unknown 核对案例，最终 705 个不同后端案例均有通过证据，不能把它说成一次全量无失败。

前端最终 49 项组件测试通过。22 条不同浏览器场景也都有通过证据：全量初次有一条使用旧技能数量/控件的断言失败，修正后单独复核。桌面审批与移动端 unknown 截图已实际查看，原始失败和截图均保留。Ruff、89 个源文件的 mypy、TypeScript、ESLint、前端构建通过；构建保留现有约 542 kB 主块体积提示。

正常数据库升级前已用原备份脚本保存业务库、回执库和工作区，并核验备份文件哈希。0022 → 0024 增量迁移后，54 张旧表的原列内容逐表一致，新增权限记录为空，没有伪造过去的批准。[迁移核验](../artifacts/verification/harness-normal-migration.json)与备份 `artifacts/backups/5cf03358c844` 留在本地，不进入产品 UI。

## 交付边界与当前环境

- 本轮零收费模型调用；真实图、PG、文件、子进程、API 和浏览器链路使用替身模型验证。模型对提示词、审批拒绝及复杂任务的语义表现未新增验证。
- 本地 Shell 仍继承应用容器可访问的文件和网络。审批控制启动时机，不是操作系统沙盒，也没有新增 AIO 或自动审查模型。
- 只读子 Agent 的能力范围保持；思考参数在新运行固定，权限在后续工具边界复核。权限收紧不能撤销已经发生的操作。
- 14 个此前不兼容的 Skill 仍禁用。旧删除操作曾被开发工具自动审批拒绝，本轮不绕过该拒绝，也不把保留目录说成删除完成。
- 当前 dev、PG、Redis 容器运行，正常 API/worker/Vite 未启动；测试临时服务已退出。依赖与迁移已经准备，用户可在 dev 终端运行 `uv run scripts/dev.py` 查看应用。
- `.env` 原值和此前未提交改动保留；没有 Git 提交/推送，没有访问桌面个人知识库，没有重新运行生产部署或旧收费效果实验。
