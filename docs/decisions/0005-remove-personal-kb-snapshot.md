# 0005：删除个人知识库初始副本，恢复空数据状态

- 状态：已接受（用户明确要求）
- 日期：2026-10-07

## 背景

项目曾将个人知识库中的 43 份 Markdown 复制为独立初始材料，并保存导入清单。当前业务设计、初始材料和存储方案仍在讨论，用户要求删除这批副本，将项目数据还原干净。

## 决策

- 删除 `data/knowledge_base/documents/` 下的全部 43 份导入副本及 `data/knowledge_base/import_manifest.json`。
- `data/knowledge_base/` 保留目录说明，当前不包含业务数据；没有已建数据库或检索索引需要重置。
- 保留个人知识库原件，以及项目代码、练习、配置、依赖和长期设计文档。
- 后续初始材料及存储方案另行确定，不沿用过去的一次性复制授权自动恢复副本。
- 项目知识库与个人知识库继续隔离；个人知识库设计可以作为参考，但不是 Agent 的默认运行时数据源。

## 后果

- 后续开发应从无业务数据状态出发，不能假定项目内已有个人知识库正文。
- 清理副本不限制 Agent 将来构建、维护和问答项目自有知识库的能力。
- 文件、数据库和索引的角色仍待设计，原有快照目录不构成已确认的存储架构。
