## 决策

实现层学习、练手和调试放在项目 `exercises/` 下，每个练习使用独立子目录。首个练习为 `01_agent_loop`，实现可以运行的单 Agent 反馈闭环。KnowledgeOps 主项目的业务范围、存储与技术选择继续单独讨论；本次不把早期里程碑草案转成正式需求。

练习沿用 LangChain/LangGraph 的标准消息、工具和图接口，重点参考 Deep Agents 的通用机制，同时保留 DeerFlow 作为完整应用设计参考。对齐包括接口、职责和设计依据，不要求一次移植全部能力。

练习代码默认使用 C 类教学注释；实战代码按重要程度与用户理解需要选择 B/C，关键实战代码同样可以采用 C。工具面向模型的描述保持简洁，长教学注释放在实现处。

## 首个练习边界

- 虚构材料保存在练习代码中；不读取或修改个人知识库，也不使用项目知识库副本。
- LangGraph 承载模型节点、工具节点与条件边；可观察消息、工具错误、预算和终态。
- 离线脚本是测试替身；真实模型模式使用同一个 Runtime，调用前需使用者显式配置并启用。
- 单独维护 pyproject、锁文件和虚拟环境，不更改主项目依赖或 M0 代码。
- 本次开发不发送真实模型请求；离线通过不视为真实模型自治或业务质量通过。
