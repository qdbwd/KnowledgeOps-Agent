# 0023：两种学习模式建立在通用长期记忆与会话连续性之上

日期：2026-10-12。依据本会话完整修订计划及长期目标授权实施。

唯一现行计划为[implementation-plan.md](../implementation-plan.md)。[旧优化计划](../exports/2026-10-12-pre-learning-optimization.source.md)是交付基线；[旧学习计划](../exports/2026-10-11-learning-modes-before-memory.source.md)的任务独立上下文及默认付费验收由新计划取代。其他既有产品合同保留，学习提问不自动成为需求。

扩展PreferenceService及其表为通用长期记忆，保留ID、来源、修订、提取回执；不建立平行偏好库。用户背景、目标、协作习惯、偏好及纠正基于真人证据，知识正文和模拟读者输出不形成用户事实。检索复用PG BM25，摘取适用DeerMem排序函数，范围/授权/版本仍由本应用控制。

会话保留短期记忆；学习任务持久保存目标、范围、框架、配置、单元、成果和许可。切换任务不清空消息，也不从历史继承许可。学习配置分人工正文和来源关联的自动部分，不相互覆盖。

交互学习一般等待真人；委托整理由程序协调后续Run，主Agent执行、读者追问、独立审读，不增加监督模型或递归委派。共同发布门绑定要求版本、草稿和真实审读子运行；人工接管如实记录，不伪造审读通过。自动Run不伪造真人消息，真实消息优先，执行顺序和真人序号分离。默认单元40模型/80工具/20搜索/1200秒活跃预算，读者/审读各最多两轮；恢复不重置，次数耗尽不等于通过。服务重启仍等待人工恢复。

参考基线DeerFlow 3f7a076972a927b4256df3e3c18b829186dd1355、Deep Agents 4bb4c7fcbf5f2ef65c39ea0134c42555926bd40b，SDK保持0.7.23。摘取保留MIT来源；存储与业务适配不整包复制DeerMem。具体设计及采用代码写architecture，实际验证写progress。

默认零付费验证，真实模型路径仍完成；图/PG/文件/队列/浏览器证明工程机制，不证明模型内容质量。旧收费对照不是默认门槛，call_model保持关闭。保留数据和工作区；不操作个人知识库、不提交推送Git、不加CI或公开部署。
