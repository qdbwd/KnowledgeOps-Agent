# 0019：关闭的辅助模型不再作为本轮效果验收对象

日期：2026-10-09。用户明确指出，既然已关闭模型调用工具，就不应继续为它完成验收实验。本决定调整本轮交付范围，取代0010、0013和0015中仍要求补完20条辅助模型对照的条款。

`call_model`的实现和按任务显式启用入口保留，新任务继续默认关闭。它不再属于本轮必须完成的效果实验：不补跑剩余配对、自主选择观察或相关真实模型重验，不为完成旧报告而临时启用它，也不把未完成实验计入长期目标的交付阻塞。

保留已经执行的实验、失败、审读和费用记录，状态是“实验未完成，已移出本轮必需范围”，不是“实验通过”或“已证明无收益”。代码中已有的关闭状态、入口拒绝、预算与恢复测试继续保留；可由正常离线回归覆盖，不为这次范围调整新增收费调用。

这项决定只针对可选的`call_model`工具及其效果实验，不关闭主Agent正常调用、必要摘要/意图解释，也不取消按需子Agent委派、知识库业务、多轮交互、Web及工程交付要求。新需求若重新需要辅助模型效果比较，再单独确定任务和支出范围。

当前设置已通过只读接口核对：`GET /api/tools/effective`返回`auxiliary=false`，`call_model.available=false`，原因是`auxiliary_disabled`。正在执行的完整业务批次使用默认关闭选项，不是辅助模型对照。
