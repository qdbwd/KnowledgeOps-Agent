日期：2026-10-09。依据现行优化计划实施，本文记录工程取舍，不扩大产品范围。

- 已阅读Deep Agents 0.7.23的`middleware/memory.py`与`graph.py`：长期背景和按需Skills分开；HITL复用LangChain中间件。本项目将偏好存PG而非开放文件编辑，以支持来源、修订、撤回和用户页面。
- 已阅读[DeerFlow固定提交的记忆中间件](https://github.com/bytedance/deer-flow/blob/7797409355cbf257923a81ab9781b706c38f9c3c/backend/packages/harness/deerflow/agents/middlewares/memory_middleware.py)及`test_memory_scope_gate.py`：区分持久、描述性、用户级信息与临时操作；接受新记忆前不先删除旧记忆。本项目合并到已有真人意图解释，不再增加后台全历史扫描或另一次模型请求。
- 已阅读同一DeerFlow提交的`mcp/client.py`、`test_mcp_binding_fencing.py`前116行和`test_mcp_config_secrets.py`的配置脱敏测试。本项目采用已锁定LangChain 1.4.3官方MCPAdapter，而非再加入旧适配包；借鉴撤回代次隔离，关闭后再开启不重新授权旧绑定。配置仅保留环境变量引用，避免保存实际密钥再靠遮罩展示。
- [LangChain的MCP适配](https://docs.langchain.com/oss/python/langchain/mcp)处理协议和工具转换；[HITL](https://docs.langchain.com/oss/python/langchain/human-in-the-loop)提供工具审查暂停机制。应用仍须保存具体业务许可、结果回执和未知结果。本项目将待确认调用保存PG并通过已有中断/手动恢复生命周期释放worker，保留LangGraph未完成工具节点；不将UI批准视为任意后续调用许可。

## 偏好合同

真人消息ID与解释器版本形成提取回执，来源原话须能在该消息中定位。明确长期偏好生效；推测、冲突和不确定范围待确认。临时要求、权限和学习掌握程度不作为长期偏好。

根任务在意图解释前冻结已有有效偏好；本条消息新提取的偏好从下一任务进入资源清单，本轮原始用户消息仍表达当前要求。普通编辑下一任务生效，停用/删除在下一模型请求前移除。历史对话不会被物理删除，也不允许用旧提取回放复活已撤回偏好。版本与用户操作不调用模型。

## MCP合同与待验证实现

配置、发现目录、许可及不可变修订均由PG保存；默认空列表。发现不授予权限，服务注解仅作审查信息。自动只读/逐次确认/禁止由用户配置。根任务冻结目录、连接修订和授权代次，子研究只接入已审查只读工具；仅知识库模式不接入MCP。

调用回执绑定run、工具调用ID、连接版本、工具Schema及参数哈希。副作用待确认时不发外部请求；批准后恢复同一个调用。已完成结果重放；已发送但没有结果的调用标记未知，不自动重试。连接禁用、工具许可撤回及Schema漂移在下一实际调用前检查；连接对象与密钥不写检查点。

外部结果保存为独立来源快照和调用出处，模型收到不可信材料说明和可补读ID。配置编辑、权限、调用、来源和UI端到端尚须验证，不能把协议夹具通过称为业务已完成。
