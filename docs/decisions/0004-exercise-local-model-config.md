## 决策

首个练习在构造在线客户端时，读取本项目根目录 `.env`，通过 `OPENAI_BASE_URL`、`OPENAI_API_KEY`、`AGENT_MODEL` 获取模型配置。按用户要求统一本地配置与示例的字段名，保留已有 URL 和密钥值，模型名为 `deepseek-flash`；读取器兼容早期的 `BASE_URL`、`API_KEY` 名称。

配置优先级为：进程环境变量 > 练习目录 `.env` > 项目根目录 `.env`。按来源先归一化别名再合并，避免旧名称破坏覆盖顺序。同一来源的标准 `OPENAI_*` 名称优先；显式空值也参与覆盖。

路径相对源码定位；使用 python-dotenv 读取配置，不扫描任意父目录，不修改全局环境。只消费三个模型配置字段，主项目的其他开关不影响练习；选择 `--mode online` 才启用真实模型客户端。
