# 部署配置与 Agent 资源

部署只支持 Docker。`.env.example` 列出进程环境及 Compose 参数；本目录保存需要结构、版本或较长正文的配置。前端通过同源 `/api` 获取运行信息，没有需要公开的供应商密钥，不额外维护一份内容重复的前端 `.env`。

| 设置 | 位置 | 生效时机 |
|---|---|---|
| 模型开关、地址、密钥、名称、超时 | `.env` | 开发重启dev.py，生产重新创建API/worker；名称/端点须匹配容量文件 |
| API/worker日志级别 | `.env` 的 `APP_LOG_LEVEL` | 开发重启dev.py，生产重新创建API/worker；支持critical/error/warning/info/debug |
| 端口、工作目录、配置与技能挂载目录 | `.env` 的 Compose 参数 | 重新执行启动入口 |
| 上下文窗口、输出预留、压缩比例、计数方法 | `model-capacity.json` | 重启当前模式的应用进程；已有任务保持容量快照 |
| 搜索后端、地区、安全过滤、默认条数、超时 | `web-search.yaml` | 下一新根任务，恢复沿用旧快照 |
| 知识库目的、整理及交互规则 | `knowledge-policy.md` | 下一新根任务；必须保留唯一版本声明 |
| 技能方法 | 根目录 `skills/` | 下一新根任务；按需读取正文 |
| 工具开关、主角色工具组 | “工具与能力”页面，PG | 新授权用于新任务，撤回在后续调用前检查 |
| MCP、子 Agent、学习偏好与角色 | 各自管理页面，PG及工作区版本 | 按原运行快照和撤回规则生效 |
| 单次任务预算 | 任务/学习配置 | 随根任务持久化；不做项目累计限制 |
| Redis 缓存开关、容量与 TTL | `.env` | 开发重启dev.py，生产重新创建API/worker |

开发dev不注入应用配置，只保留非业务的开发标志；`dev.py`每次读取当前`.env`，生成基础服务/测试连接与固定目录，再传给API/worker/Vite。`--run`可用同一配置执行单条调试或测试命令。显式进程覆盖仍优先，离线验证设置`MODEL_CALLS_ENABLED=false`。普通应用参数变化只需重启进程，不自动重启运行中的任务。生产API/worker通过`env_file`在创建容器时注入文件，显式`environment`再覆盖内部连接/路径；一次性init强制离线，web/PG/Redis并不接收整份文件。生产普通配置变更需要重新创建受影响容器，单纯restart不刷新环境；无需重新构建镜像。Docker端口、挂载与服务配置仍需通过Compose更新，完整步骤见[启动指南](../README.md#修改后怎样生效)。

`.env.example`是可提交的配置合同，普通默认值可以公开，密钥和密码留空；本机`.env`保存用户值且不提交。增加配置时同步模板和本机缺项，但不能覆盖已有模型开关、地址、密钥或密码。`Settings`按构造参数、进程环境、根`.env`、默认值的顺序读取；资源加载器读取dev.py或Compose传入的路径变量。默认值是回退，不能用它代替实际读取和使用配置。开发终端手工export的覆盖值需自行unset，否则它仍会优先于文件。

专用工作区的宿主目录由`AGENT_WORKSPACE_HOST`选择；内部`WORKSPACE_ROOT=/data/agent-workspace`与`SOURCE_STORAGE_ROOT=/data/agent-workspace/uploads/originals`在生产由Compose、开发由dev.py设置，配合挂载和备份，不在模板中列为可修改选项。退休的`KNOWLEDGE_BASE_ROOT`不再读取。

内置数据库用户名和三个数据库名是本地Compose拓扑约定，不是用户偏好；不暴露修改它们而忘了修改初始化脚本、测试隔离与备份校验。PG密码和网页端口可配置。生产数据库/Celery DSN由Compose注入；开发由dev.py按当前文件及固定服务名生成，密码进行URL编码，显式DSN可供调试/隔离测试覆盖。已有数据库改密码还须实际修改PG账户。Redis加速层的RUNTIME_REDIS_URL属于应用配置，可按上表刷新。当前单用户部署绑定127.0.0.1；增加允许的HTTP主机名不等于实现认证或授权公网发布。

API 文本字段长度、文件管理区权限、子 Agent 只读边界、根预算共享、worker 独占租约等属于程序合同，不为了增加“配置数量”就做成任意开关。检索分段影响持久索引，调整需要索引版本及重建，不能作为即时环境参数偷偷更改已有数据。

模型适配目前以 DeepSeek Chat Completions 为验证对象。其他设备可调整供应商地址、密钥及显式容量档案；未经验证不能声称支持任意提供商。不要把物理窗口、应用工作窗口和输出长度混为一项：默认继续为 262,144 tokens 工作窗口、90% 压缩阈值。

自定义文件位置可用 `.env.example` 中的 `*_PATH`/`SKILLS_DIRECTORY` 容器路径。文件错误会在请求前报告，不能静默回退到其他渠道或默认规则。密钥始终在环境中，不写入本目录，不放入浏览器 `VITE_*` 变量。
